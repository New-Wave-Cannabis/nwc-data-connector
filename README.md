# New Wave Cannabis data connector: public pages

Static pages for the New Wave Cannabis data connector for QuickBooks Online, served by GitHub Pages:

- `index.html`: the landing page
- `eula.html`: End-User License Agreement
- `privacy.html`: Privacy Policy
- `callback.html`: the OAuth redirect page; it shows the one-time connection code in the browser and sends it nowhere

No server, no scripts from other sites, no cookies or tracking.
